# ODIR blinded CAM review

English clinician review: seven disease categories, five images each (35 cases).
The subset was sampled with seed 42, with distinct patients within each disease, without using clinician judgments or model scores. The original A/B assignments are retained.

Open index.html in Chrome or Edge. Enter an anonymous reviewer ID, complete the four judgments, and select Save and next. Export a JSON backup after each session and return the final JSON to the researcher. Responses remain in the browser; this site does not collect or upload them. Avoid private browsing.

Only clinician-facing files are published. Researcher pages, method mappings and completed reviews are excluded. Subset JSON results retain original case/package identities for local researcher analysis.
